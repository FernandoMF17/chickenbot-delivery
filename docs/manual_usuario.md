# Manual de Usuario

## 1. Introducción

### Objetivo

Este manual describe el funcionamiento de ChickenBot Delivery para los diferentes tipos de usuarios del sistema.

Los módulos documentados son:

- Cliente (Bot de Telegram)
- Administrador (Panel Web)
- Repartidor (Bot de Telegram)

---

# 2. Cliente - Bot de Telegram

## Inicio

El usuario inicia la conversación enviando:

/start


### Menú principal

Desde el menú principal el usuario puede:

- Ver categorías
- Ver productos
- Consultar carrito
- Consultar estado del pedido


---

## Realizar un pedido

Pasos:

1. Seleccionar una categoría.
2. Elegir un producto.
3. Indicar la cantidad.
4. Agregar al carrito.
5. Confirmar el pedido.



---

## Compartir ubicación

Después de confirmar el pedido, el sistema solicita compartir la ubicación de entrega.



---

## Estado del pedido

El usuario puede consultar el estado de su pedido.

Estados disponibles:

- Pendiente
- Pagado
- En camino
- Entregado



---

# 3. Administrador

## Inicio de sesión

Ingresar:

- Usuario
- Contraseña



---

## Dashboard

El panel principal permite acceder a:

- Categorías
- Productos
- Pedidos
- Repartidores


---

## Gestión de categorías

El administrador puede:

- Crear
- Editar
- Eliminar categorías


---

## Gestión de productos

Permite:

- Registrar productos
- Modificar información
- Actualizar stock


---

## Gestión de pedidos

El administrador puede:

- Consultar pedidos
- Modificar estados



---

## Gestión de repartidores

Permite:

- Registrar repartidores
- Editar información
- Activar o desactivar repartidores



---

# 4. Repartidor

## Acceso

El repartidor inicia sesión mediante su código de acceso.


---

## Recepción de pedidos

El sistema muestra los pedidos asignados.

---

## Confirmación de entrega

El repartidor registra la evidencia fotográfica de la entrega.

---

# 5. Recomendaciones

- Mantener conexión a Internet.
- Compartir la ubicación correctamente.
- Verificar la información antes de confirmar un pedido.

---

# 6. Conclusión

El manual proporciona las instrucciones necesarias para que clientes, administradores y repartidores utilicen correctamente ChickenBot Delivery.
